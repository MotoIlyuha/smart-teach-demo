# SmartTeach - Образовательная платформа нового поколения

**SmartTeach** — это образовательная веб-платформа, разработанная на React и TypeScript с использованием Supabase для бэкенд части. SmartTeach предназначена для поддержки интерактивного, индивидуального и группового обучения, обеспечивая как учителей, так и учеников полезными инструментами для организации и мониторинга учебного процесса.

> *Важно! Проект находится на стадии активной разработки. Многие из перечисленных возможностей не реализованы или требуют доработки. Код проекта не является образцом идеального стиля и может содержать баги и временные решения.*

## Описание проекта

**SmartTeach** — это дипломный проект, разработанный мной, студентом 4-го курса бакалавриата Смоленского Государственного Университета. Целью проекта является создание удобной образовательной среды для учеников, учителей и администраторов учебных заведений. Платформа разработана с использованием React, TypeScript и библиотек, таких как ReactFlow и React TipTap, а в качестве бэкенда используется Supabase.

## Основные функции и возможности

### Регистрация и авторизация

- Возможность регистрации и авторизации по логину или электронной почте.
- В будущем будет реализована поддержка сторонних провайдеров (Google, ВКонтакте, Госуслуги и другие).

Личный кабинет предоставляет пользователям возможность управлять своей учебной деятельностью:

- **Основная информация**: Отображение имени, фамилии, даты рождения, роли, а также фото профиля пользователя.
- **Статистика и роль-зависимая информация**: В личном кабинете ученика отображается статистика прогресса прохождения курсов, такие как количество набранных баллов и статус обучения (например, "Сейчас проходит курс Математика 6 класс"). В разработке находятся фильтрация и сортировка данных статистики.

### Управление курсами и группами

Платформа предоставляет учителям и администраторам обширные возможности по управлению курсами и группами:

- **Создание и редактирование курсов**: Учителя могут создавать курсы, добавлять к ним задания, определять условия доступа и публиковать их. Курсы могут быть как публичными, так и доступными по коду, а также включать платные элементы (в разработке).
- **Управление группами**: Учителя могут создавать группы учеников, модерировать их и добавлять участников. Доступ к группе может быть открыт через приглашение или добавление по логину.

### Структура курса (КРУЗВО)
**КУРС → РАЗДЕЛ → УРОК → ЗАДАНИЕ → ВОПРОС → ОТВЕТ**

* Курс: содержит название, описание, настройки приватности и банк заданий.
* Раздел: включает траекторию обучения и связанные уроки.
* Урок: может быть стартовым, обычным, дополнительным или контрольной работой.
* Задание: состоит из вопросов и проверяет определенные элементы знаний.
* Вопросы: разные [типы вопросов](#Банк заданий и вопросы) для оценки знаний ученика.
* Ответы: варианты ответа или поля для ввода, в зависимости от типа вопроса.

### Траектории обучения и графы курсов

Траектория обучения представляет собой направленный граф уроков, связанный с конкретным курсом. Это визуальное представление помогает ученикам и учителям отслеживать прогресс:

- **Направленные графы**: Курсы состоят из разделов, каждый из которых представляет собой граф уроков. Доступность уроков определяется результатами предыдущих занятий и заданными условиями (например, "Всегда доступен" или "Доступен при наборе баллов").
- **Условия доступа**: Учителя могут гибко настраивать условия доступности для учеников, чтобы создать персонализированное обучение.

### Типы уроков

На платформе реализованы различные типы уроков, чтобы поддерживать разные этапы учебного процесса:

- **Стартовая контрольная**: Предназначена для оценки начальных знаний ученика и определения, какие уроки доступны в графе обучения.
- **Обычный урок**: Проверяет конкретное знание и включает задания для его закрепления.
- **Дополнительный урок**: Необязателен для прохождения, но ученик может его пройти, чтобы улучшить свой рейтинг и набрать дополнительные баллы.
- **Контрольная работа**: Проверяет, насколько ученик освоил материалы раздела, и начисляет баллы за прохождение. Может включать задания, уже пройденные ранее.

### Дерево знаний

## Установка и настройка

Для того чтобы развернуть проект локально, следуйте инструкциям ниже:

### Требования

- Node.js v14+ и npm
- Supabase аккаунт для хранения данных

### Установка

1. Клонируйте репозиторий:

   ```bash
   git clone https://github.com/MotoIlyuha/smart-teach-demo.git
   cd SmartTeach
   ```

2. Установите зависимости:

   ```bash
   npm install
   ```

3. Настройте Supabase:

    - Создайте проект в Supabase и сохраните API ключи.
    - Чтобы подключиться к Supabase, необходим VITE\_SUPABASE\_ANON\_KEY, который я предоставить не могу. Убедитесь, что у вас есть этот ключ для настройки подключения.
    - Настройте переменные окружения в файле `.env`.

4. Запустите приложение:

   ```bash
   npm start
   ```

## Технологии и инструменты

- **Frontend**: React, TypeScript, ReactFlow (визуализация графов), React TipTap (текстовый редактор).
- **Backend**: Supabase для управления данными и аутентификации.
- **UI**: Ant Design для оформления интерфейса.

## Будущие функции

Планируется внедрение следующих возможностей:

1. **Регистрация через сторонние провайдеры**: Google, ВКонтакте, Госуслуги и другие.
2. **Роли**: Родители, Репетиторы, Директора учебных заведений с уникальными правами доступа.
3. **ИИ-помощник**: Функция "ИИ, помоги!", которая будет помогать учителям в создании курсов и заданий, используя обученную нейронную сеть.
4. **Дополнительные типы вопросов**: Включение вопросов типа "Сортировка" и "Соотнесение".
5. **Таблица лидеров**: Для отображения успехов учеников и создания духа соревнования.
